# 🚀 營運自動化全套組 (Ops Automation Suite)

本專案整合了三大娛樂城品牌（贏麻了、爽爆、茄子）的全套自動化營運、風控、機台監控與社群活躍系統。

---

## 📂 目錄模組架構

- **`01-operations-data/`**：【營運數據自動更新】
  - 每日 08:00 自動從三平台抓取營收、洗碼量、活躍會員數據，自動填入 Google 試算表，並推播日報至 Telegram 私人管理群。
  - 包含月報簡報自動彙整模組。
- **`02-daily-gift/`**：【每日新手禮包與 LINE 推播】
  - 每日 07:00 匯出新註冊會員名單，透過試算表 Apps Script 排除異常 IP，自動建立 18:00 生效之遊戲免費禮包。
  - 自動同步 LINE UID 受眾並預約當日 18:00 推播，全流程由 TG 機器人回報。
- **`03-bigwin-monitor/`**：【爆分與出金監控 & 洗碼量同步】
  - **爆分注單掃描**：單筆出分達門檻即刻觸發內部 Telegram 警報，附帶「一鍵發送喜報到社群」按鈕。
  - **出金風控監控**：自動比對幣商出金，即時折算台幣匯率與計算當日玩家淨輸贏。
  - **遊戲洗碼量同步**：定期抓取玩家洗碼量同步至小遊戲 D1 資料庫。
  - **`cloud-worker/`**：Cloudflare Worker 雲端純 API 版本，免開瀏覽器即可每 5 分鐘運行。
- **`04-slot-sniper/`**：【機台狙擊手（撿台機器人）】
  - 包含贏麻（ATG）、爽爆、茄子三平台專用選台情報爬蟲。
  - 定時前往遊戲大廳（ATG 伺服器全球通暢，無白名單限制），撈取未開高轉數空台，生成圖文推播至玩家社群。
- **`05-community-bot/`**：【社群小精靈娛樂館】
  - Telegram 社群互動娛樂：每日求籤、金庫密碼、密室逃脫、海龜湯、臥底狼人殺。
- **`scheduler/`**：【內建統一排程引擎】
  - 取代 Windows 繁雜的 18 個工作排程器，開箱即常駐，跨平台支援。

---

## 🛡️ 安全與機密管理

- 專案已做徹底脫敏，絕無硬編碼真實密碼或 Token。
- 初次使用請將 `config/.env.example` 複製為 `.env`，填入相應金鑰。
