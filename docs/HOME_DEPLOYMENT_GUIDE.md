本指南專為你在家裡電腦（脫離公司環境）進行開發、調試與排程運行所設計。

## 📌 一、 核心認知：什麼在雲端？什麼依賴公司白名單？

| 模組項目 | 雲端 / 家中可行性 | 白名單限制 | 建議運作方式 |
|---|---|---|---|
| **🎰 撿台機器人 (贏麻/爽爆/茄子)** | **100% 雲端自由運行** | ❌ **無限制**<br>(ATG 遊戲伺服器為全球開放) | 可直接部署於 Linux 雲端主機或在家電腦背景定時跑 |

## 🚀 二、 在家電腦初次安裝步驟

### 1. 下載專案
在你的家裡電腦，開啟終端機（Terminal / PowerShell）：
```bash
git clone https://github.com/micisachen63-gif/-.git ops-automation
cd ops-automation
```

### 2. 安裝依賴環境
```bash
npm install
```
若需要執行無頭爬蟲（撿台機器人）：
```bash
npx playwright install chromium
```

### 3. 配置金鑰環境變數
複製範本並填入您的 Telegram Bot Token 與帳號：
```bash
cp .env.example .env
```

## 🛠️ 三、 各模組手動測試與排程指令

### 1. 撿台機器人（隨時可在家跑，無白名單限制）
- 爽爆選台測試：
  ```bash
  npm run sniper:sb
  ```
- 茄子選台測試：
  ```bash
  npm run sniper:qz
  ```

### 2. 營運數據表（手動測試）
- 乾跑不寫入測試：
  ```bash
  node 01-operations-data/run.mjs --dry-run
  ```

### 3. 爆分監控（純 API 模式）
- 啟動監控測試：
  ```bash
  npm run monitor
  ```

### 4. 啟動內建統一排程器（無人值守）
不用開啟 18 個 Windows 工作排程器，直接運行內建定時調度引擎：
```bash
npm start
```
它會依時段自動排程：
- 07:00 新手禮包
- 08:00 營運數據更新
- 每 5 分鐘 爆分與出金檢測
- 固定時段 撿台機器人推播

## 💡 四、 遠端作業最佳實踐（完美脫離公司卡頓電腦）

1. **代碼開發、修改、新增功能**：
   - 100% 在家裡的電腦完成，享受家裡的高速網路與硬體效能。
   - 修改完後執行 `git push` 推到 GitHub。
2. **在公司電腦同步**：
   - 透過「遠端桌面」連回公司電腦，打開終端機輸入：
     ```bash
     git pull
     ```
   - 這樣公司電腦永遠只是「安靜執行最新代碼的白名單執行器」，你再也不必忍受透過遠端桌面在公司電腦上痛苦寫程式！
